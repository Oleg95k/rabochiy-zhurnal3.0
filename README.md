# Рабочий журнал 3.0 — прототип

## Что уже есть
- Общий список задач в интерфейсе
- Выбор сотрудника (демо-список до 10 человек)
- Категории, срок, приоритет и комментарий
- Фильтры по сотруднику, статусу, категории и поиск
- Статусы: новая → в работе → выполнена
- Статистика: всего, активные, выполненные, просроченные
- Сохранение в localStorage текущего браузера

## Важно
Это пока интерфейсный прототип. Данные хранятся только в браузере и не синхронизируются между коллегами.
Общий пароль в клиентском коде не обеспечивает реальную безопасность. Для командного запуска подключить Supabase:
- Auth (лучше индивидуальные аккаунты; если оставлять общий пароль — только через серверную проверку)
- PostgreSQL таблица tasks
- Row Level Security policies
- Realtime subscriptions
- Серверная функция для валидации общего пароля, если выбран такой режим

Не вносите реальные персональные данные должников в прототип.
